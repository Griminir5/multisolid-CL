# CLI guide

This guide is an outline. For installation and a first run, see the
[repository README](../README.md#install-the-full-repository-from-source).

Planned coverage:

- The four case input files, relative paths, units, and validation.
- Running a single case and generating input diagrams and plots.
- Programs, solver settings, compiled execution, and caches.
- Batch axes, concurrency, timeouts, and summaries.
- Reports, NetCDF datasets, manifests, exit codes, and troubleshooting.
- Loading cases and results through the Python API.

Current command help is available through `python -m packed_bed --help` and
`python -m packed_bed batch --help`. Complete inputs are in the
[simulation examples](../examples/simulations/).
