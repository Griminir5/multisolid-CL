# Welcome screen

Start here to create a project or return to work you have already saved.
A project keeps your cases, parameter studies, plugins, and report layouts
together in one folder.

## Screen controls

| Control | What it does |
| --- | --- |
| Create new project | Creates an empty project in a new folder. |
| Open existing project | Opens a project folder or its `project.json` and resumes it in place. |
| Import archived project | Imports a `.msproject` archive into a new folder. Archives contain inputs and layouts; run the imported cases to create results. |

## Create or import dialog

| Field or option | What it does |
| --- | --- |
| Project name | Names the project and its new folder. |
| Location | Absolute path of the parent folder in which to create the project. |
| Project folder | Shows the full destination formed from Location and Project name. |

## Where your work lives

Keep working projects in a local folder outside the application installation.
Use project archives when transferring inputs between computers. Creating or
importing a project requires a new destination folder.

The **Help** menu is available before you open a project. It includes the
full guides, screen references, search, troubleshooting, About, and licences.
**About MultiSolid** shows the version and a diagnostic summary you can copy.
Start with [Getting started](getting-started.md) for the complete first-run workflow, or
read [Projects and navigation](../GUI-GUIDE.md#projects-and-navigation).
