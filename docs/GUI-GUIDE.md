# GUI guide

This guide is an outline. Use the [current desktop reference](../desktop/README.md)
while its content is migrated here. Installation instructions are in the
[repository README](../README.md#install-the-desktop-application).

Planned coverage:

- Creating, opening, importing, exporting, and recovering projects.
- Editing cases: General, Chemistry, Bed, Program, and Report.
- Running cases, choosing solvers, managing results, and diagnosing failures.
- Parameter studies and reusable definitions.
- Plot windows, case reports, project Results, and Excel export.

Plugin workflows will be covered in the [plugin guide](plugins.md).
