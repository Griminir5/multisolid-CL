# Plugin guide

This guide is an outline. The [existing plugin reference](../PLUGINS.md) remains
available until its content is consolidated here.

Planned coverage:

- Installing and enabling data-only and Python plugins, including local code approval.
- Selecting species and reaction families, creating variants, and replacing definitions.
- Plugin folders, manifests, units, parameter declarations, and the Python API.
- Developing property correlations and kinetics; generating metadata and checking packages.
- Sharing `.msplugin` archives and projects, updating plugins, and troubleshooting.

See the [worked examples](../examples/plugins/README.md) and
[waste iron plugin](../plugins/waste_iron/README.md) for existing implementations.
